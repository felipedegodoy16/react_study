# ⚛️ React Projects

Este repositório reúne uma coleção de pequenos projetos desenvolvidos com **React**, criados com o objetivo de praticar conceitos, testar novas tecnologias e evoluir minhas habilidades no desenvolvimento frontend.

Além de servir como um ambiente de aprendizado, este repositório funciona como um **backup dos projetos** que desenvolvo e como parte do meu **portfólio**, registrando minha evolução ao longo do tempo.

## 📂 Estrutura

Cada pasta representa um projeto independente, podendo utilizar diferentes ferramentas e bibliotecas conforme o objetivo do estudo.

Exemplo:

```text
react-projects/
├── project-01/
├── project-02/
├── project-03/
└── ...
```

## 🚀 Tecnologias

Os projetos podem utilizar diferentes tecnologias, incluindo:

* React
* TypeScript
* JavaScript
* Vite
* Tailwind CSS
* React Router
* Context API
* Axios
* Outras bibliotecas conforme a necessidade de cada projeto

## 🎯 Objetivo

Este repositório tem como principais objetivos:

* Consolidar conhecimentos em React.
* Experimentar novas bibliotecas e padrões de desenvolvimento.
* Criar projetos práticos para estudo.
* Registrar minha evolução como desenvolvedor.
* Manter um backup organizado dos projetos que compõem meu portfólio.

## 📌 Observações

Os projetos presentes aqui podem variar em nível de complexidade. Alguns são estudos rápidos de um conceito específico, enquanto outros possuem uma estrutura mais completa.

Conforme novos projetos forem desenvolvidos, este repositório continuará sendo atualizado.
